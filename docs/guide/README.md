# User guide

How to install, set up and use Sidera. For the exact behavior of each command,
protocol and file, see the [engineering references](../references/README.md); this
guide says how to get things done.

| Page | Read it to |
| ---- | ---------- |
| [Install and run Sidera](install.md) | Check the supported platforms, install from a release archive or from source, keep the daemon running, and open the port in the firewall. |
| [Getting started](getting-started.md) | Take two machines from nothing to a first message between agents: create nodes, install adapters, add presets, pair, start a session on the other machine. |
| [Working with agents](agents.md) | Learn how an agent sends, receives and starts sessions through Sidera, and how to write a preset's instructions. |
| [Adapters](adapters.md) | See what the Claude Code, Codex, Hermes and console adapters support and how they differ: sessions, controllers, wake-ups, interrupts and permission questions. |
| [Operations](operations.md) | Check health, read logs, upgrade, change or remove an adapter, back up the self-revocation, troubleshoot, and see the known limits. |

To let an AI agent do the setup and then work through Sidera, give it
[`docs/agent-guide.md`](../agent-guide.md). It is self-contained.

Everything in this directory is English.
