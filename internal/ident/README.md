# ident

Identifiers for nodes, people and endpoints. Read [../README.md](../README.md)
first for the conventions every contract package follows.

## Entry points

| Type         | Size     | Meaning                                                       |
| ------------ | -------- | ------------------------------------------------------------- |
| `NodeID`     | 32 bytes | A node. A digest of the node's long-term identity public key. |
| `PersonID`   | 32 bytes | A person. A digest of the person's root public key.           |
| `EndpointID` | 16 bytes | An endpoint on a node. Random, generated by that node.        |
| `Address`    | -        | `{Node, Endpoint}`: one endpoint on one node.                 |

The digest derivations for `NodeID` and `PersonID` are not part of this package
yet; they are added together with the record formats that carry the keys. Until
then a `NodeID` or `PersonID` is only an opaque 32-byte value.

For each of the three identifier types `T`:

- `TFromBytes([]byte) (T, error)` rejects input of the wrong length and the
  all-zero value.
- `ParseT(string) (T, error)` and `String()` use lowercase hex.
- `Bytes()` returns a copy; `IsZero()` reports the unset value.

`NewEndpointID(io.Reader)` reads a new `EndpointID` from the supplied
randomness source (callers pass `crypto/rand.Reader`) and rejects an all-zero
result. `ParseAddress` and `Address.String` use the form `<node>/<endpoint>`.

Errors wrap `ErrLength`, `ErrZero` or `ErrText`; match them with `errors.Is`.

## Invariants

- Lengths are fixed. The identifier types are structs with an unexported array,
  so a value cannot be built from a wrong-length slice, and they stay
  comparable and usable as map keys.
- The zero value means "unset" and is never a valid identifier: constructors and
  parsers refuse it, so a non-zero value obtained from this package is valid.
  An `Address` is zero if either part is.
- An `EndpointID` never changes once its node has issued it.
- The only accepted text form is canonical lowercase hex of the exact length;
  uppercase, prefixes and separators are rejected.

## Provisional

The text form is provisional and will be fixed together with the record
encoding.
